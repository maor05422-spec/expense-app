# תקציב הבית - מאור ואנאל

אפליקציית ניהול הוצאות משותפת, בנויה עם Next.js + Supabase.

## מה יש באפליקציה

- **קטגוריות ותקציב חודשי** - לכל קטגוריה תקציב חודשי, ומעקב מול ההוצאה בפועל
- **תנועות** - הוספת הוצאות/הכנסות, שיוך לקטגוריה ולמי ששילם, עם ניווט בין חודשים
- **הוצאות קבועות/חוזרות** - שכירות, ביטוחים, מנויים - עם כפתור ליצירת התנועות של החודש
- **יעדי חיסכון** - יעד סכום, הפקדות, בר התקדמות, וחישוב "כמה לחודש כדי להגיע בזמן"
- **דשבורד עם גרפים** - התפלגות הוצאות לפי קטגוריה, מגמת 6 חודשים, תקציב מול בפועל
- **בית משותף** - שני משתמשים (מאור ואנאל) מתחברים בנפרד ורואים את אותם הנתונים בדיוק

## שלב 1: הקמת Supabase (חינמי)

1. היכנסו ל-[supabase.com](https://supabase.com) וצרו חשבון ופרויקט חדש
2. בתפריט הצד: **SQL Editor** → הדביקו את כל התוכן של הקובץ `supabase/migrations/0001_init.sql` → **Run**
3. בתפריט הצד: **Project Settings → API** → העתיקו את:
   - `Project URL`
   - `anon public` key

## שלב 2: הרצה מקומית

```bash
npm install
cp .env.example .env.local
# ערכו את .env.local והדביקו את ה-URL וה-anon key מ-Supabase
npm run dev
```

פתחו את http://localhost:3000 - יופיע מסך הרשמה. צרו חשבון, ואז במסך "כמעט מוכנים" צרו בית משותף חדש.
כדי שגם מאור וגם אנאל יראו את אותם הנתונים: המשתמש הראשון יוצר בית (מקבל קוד הזמנה שמופיע למעלה בכל מסך),
והשני נרשם ובוחר "הצטרפות לבית" עם אותו קוד.

## שלב 3: פריסה לאינטרנט (Vercel, חינמי)

1. העלו את התיקייה הזו ל-GitHub (repo חדש)
2. היכנסו ל-[vercel.com](https://vercel.com) → **New Project** → בחרו את ה-repo
3. בהגדרות הפרויקט ב-Vercel, הוסיפו את משתני הסביבה `NEXT_PUBLIC_SUPABASE_URL` ו-`NEXT_PUBLIC_SUPABASE_ANON_KEY` (אותם ערכים מ-.env.local)
4. Deploy - תקבלו כתובת אינטרנט אחת שגם מאור וגם אנאל יכולים להיכנס אליה מכל מכשיר

## מבנה הפרויקט

```
src/app/login/          מסך התחברות/הרשמה
src/app/onboarding/      יצירת/הצטרפות לבית משותף
src/app/dashboard/       דשבורד + כל המסכים (מוגנים בהתחברות)
  ├─ categories/          קטגוריות ותקציב
  ├─ transactions/         תנועות (הוצאות/הכנסות)
  ├─ recurring/            הוצאות קבועות
  └─ goals/                יעדי חיסכון
src/lib/supabase/         חיבור ל-Supabase (client, server, middleware)
src/components/           רכיבי UI וגרפים
supabase/migrations/      סכמת מסד הנתונים המלאה
```

## מה עוד אפשר להוסיף בהמשך (לא חובה)

- התראות לתשלומים קרובים (Push/אימייל)
- ייצוא לאקסל
- סריקת קבלות (OCR)
- מצב כהה (Dark mode)
